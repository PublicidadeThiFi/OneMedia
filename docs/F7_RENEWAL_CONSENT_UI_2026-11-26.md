# F7 renewal consent UI (candidate)
Only an explicit server capability enables the selection. NONE defaults to no consent; bounded schedules preserve the selected end, recurring requires its separate server flag; continuous all-day hides the end date and supplies a finite technical horizon of 29 days. A replacement revokes previous consent and uses the reviewed mode. The exact current grant can be revoked by confirmation; revocation is not pause or immediate playback stop. No background POST, no local grant storage, no claims of successful playback. An older backend remains compatible. Chain replacement, future switch, pause/resume/restore remain pending; no rollout until F7/F8 completion.
